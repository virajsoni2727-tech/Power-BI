# 📊 Superstore Sales Dashboard — Power BI

A Power BI data visualization project built using the **Sample Superstore** dataset. The dashboard analyzes sales, profit, customers, products, categories, sub-categories, and regional performance through interactive visuals and filters.

## 📌 Project Overview

This project demonstrates how Power BI can transform Superstore sales data into an interactive business dashboard. It focuses on sales performance, profitability, product performance, and regional trends.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify top-performing products and categories
- Compare sales across regions and locations
- Understand category and sub-category performance
- Track business trends using interactive charts
- Provide an easy-to-use dashboard for business insights

## 🚀 How to Run

1. Download the project files.
2. Open `Superstore_Sales(2).pbix` in **Power BI Desktop**.
3. If Power BI requests the data source, select `Sample - Superstore(1).csv`.
4. Refresh the dataset if required.
5. Use the slicers and visuals to explore the dashboard.
